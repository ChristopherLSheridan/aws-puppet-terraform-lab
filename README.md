# AWS Puppet Terraform Lab

A hands-on Infrastructure-as-Code and configuration management
project demonstrating AWS infrastructure provisioning, Linux
automation, and CI/CD practices.

## Technologies

- AWS (EC2, VPC, IAM)
- Terraform
- Puppet
- GitHub Actions
- Ubuntu Linux
- Nginx
- PHP-FPM

## Project Objectives

1. Provision AWS infrastructure using Terraform.
2. Configure Linux servers using Puppet.
3. Automate infrastructure validation with GitHub Actions.
4. Demonstrate configuration drift detection and remediation.
5. Implement secure infrastructure management practices.

## Architecture

Planned infrastructure:

- Puppet Server: Centralized configuration management
- Web Server: Nginx managed by Puppet
- Application Server: PHP-FPM managed by Puppet

## Status
